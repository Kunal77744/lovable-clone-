Wildvault Run drops players onto a three-lane causeway filled with shifting hazards, relic chains, and rising speed. It plays instantly in the browser with keyboard, swipe, and touch controls, with no account required.

Full description

Wildvault Run is an original browser endless runner set on a collapsing causeway through ancient forest ruins. Shift lanes, vault barriers, slide beneath hazards, and collect sunshards as the course accelerates. Personal bests, a shared daily route, score-challenge links, and instant retries turn each short run into a new target. The game works on desktop and mobile, requires no account, and includes an installable app shell for a quicker return.

Controls

One course, two natural inputs.

The opening guide adapts to the latest input on keyboard, touch, and hybrid devices. Every movement is available before the first obstacle.

Keyboard

← → shift lanes, ↑ vaults, and ↓ slides. Press P or Esc to pause and resume an active run.

Touch

Swipe left or right to shift, up to vault, and down to slide. On-screen movement buttons stay available during the run, with a dedicated pause control above them.
