# Wildvault Run

A responsive, original endless-runner game built for the browser. Move between
three lanes, jump low obstacles, slide under arches, collect relics, and survive
an increasingly fast run through the Wildvault.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated static site is written to `dist/` and can be deployed directly to
Vercel. Assets use relative paths, so the same build is portable to GitHub Pages;
the included Pages workflow can publish it after Pages is enabled for the repository.
